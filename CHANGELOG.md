# Changelog

Release notes for each version. The release workflow copies a version's section into the
update feed, so write entries for people using the app.

## 0.1.0

The first public release.

- **Triage one file at a time:** keep, delete, tag with categories, or skip, with previews of
  text and code (syntax-highlighted), images (including AVIF, and HEIC on macOS), video,
  audio, PDFs, Office and iWork documents, and zip, 7z, RAR and tar archives.
- **Nothing changes until you commit.** Review every decision first, then deletions go to a
  Degreaser trash folder (or are deleted permanently, if you choose), with a report and a
  catalog of what you kept.
- **Local folders and SMB shares**, with downloads and previews that keep up on slow networks.
- **Sync between computers** through the project folder: one computer decides at a time, and
  the others can open the project read-only.
- **Duplicates:** byte-identical files are found in the background, flagged in triage, and can
  be deleted automatically once you've kept one copy.
- **Rules** decide common junk (system files, caches, build output) and things to always keep.
- **Preferences:** theme, keyboard shortcuts, preview limits, defaults for new projects, and
  automatic updates.
